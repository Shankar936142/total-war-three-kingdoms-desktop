## 🛠️ Troubleshooting

**The application cannot find my game folders.**
Use the folder picker to point it at the correct location manually. If you installed the game on a secondary drive, the default detection may not look there.

**A folder shows as empty when I know it has files.**
Close the game before opening the application. Some files are locked while the game is running and cannot be read.

**Photos do not appear in the gallery.**
Confirm the photo folder path in the application matches the folder where your screenshots are actually being saved.

**The application will not start.**
Make sure you obtained it from the releases page linked above, and confirm your operating system meets the requirements listed earlier.

**Something looks wrong after a game update.**
Game updates occasionally change folder layouts. Check the releases page for a newer version of the application that accounts for the change.
